Job Description


Job Overview

We are looking for a passionate Generative AI Intern eager to work on cutting-edge AI technologies. This role is ideal for candidates who have a strong foundation in Python and machine learning fundamentals, along with a growing interest in large language models (LLMs), prompt engineering, and agent-based systems.

Key Responsibilities:

Core Fundamentals

Python proficiency (data structures, OOP, async programming)
Familiarity with ML fundamentals (supervised/unsupervised learning, evaluation metrics)
Basic understanding of transformer architecture and attention mechanisms
Experience with at least one LLM API (OpenAI, Anthropic, Google Gemini)

Agent-Relevant Skills

Prompt engineering (few-shot, chain-of-thought, system prompts)
Basic experience with LangChain, LlamaIndex, or similar orchestration frameworks
Understanding of RAG (Retrieval-Augmented Generation) concepts
Familiarity with vector databases (Pinecone, Weaviate, ChromaDB)
API integration and basic tool-use patterns

Nice to Have

Exposure to function calling / tool-use in LLMs
Personal projects or hackathon work involving chatbots or AI assistants
Basic knowledge of Git and collaborative development
